# Amazon Appstore Listing Notes for Humbly Plural

## App title
Humbly Plural

## Short description
Private plural system manager for member tracking, fronting logs, journal notes, and system statistics.

## Full description
Humbly Plural is a privacy-first plural system tool for managing members, tracking who is fronting, recording journal entries, and viewing system statistics.

- Add and edit system members with names, pronouns, roles, and bios
- Track current fronting with switch start/end times
- Support co-fronting and notes during switches
- Write journal entries and view them in order
- View total switches, most active members, and recent activity
- Save all data locally in JSON files with no internet required

Humbly Plural is designed for plural systems who want a private, self-hosted alternative to commercial apps.

## Keywords
plural system, DID, OSDD, fronting, member tracker, journal, switch tracker, privacy, self-care, mental health

## Privacy statement
All data is stored locally on the device. Humbly Plural does not collect or transmit any personal information.
