# Humbly Plural Web App - Hosting Guide

Your web app is ready! It's a single HTML file that runs entirely in the browser and stores data locally.

## Quick hosting options (all free)

### Option 1: Replit (Easiest)
1. Go to https://replit.com
2. Sign up with email or GitHub
3. Click "Create" and choose "HTML/CSS/JavaScript"
4. Delete the default files
5. Create a new file called `index.html`
6. Copy the entire content from `index.html` in this folder
7. Paste it into the Replit file
8. Click "Run"
9. Replit gives you a public URL like `https://projectname.replit.dev`

### Option 2: Glitch
1. Go to https://glitch.com
2. Sign up
3. Create a new project from scratch
4. Replace `index.html` with the content from this folder's `index.html`
5. Delete the other default files
6. Your app is live at `https://projectname.glitch.me`

### Option 3: GitHub Pages
1. Create a GitHub account at https://github.com
2. Create a new repository called `humbly-plural`
3. Upload `index.html` from this folder
4. Go to Settings > Pages
5. Set source to `main` branch and `/(root)` folder
6. Your app is live at `https://yourusername.github.io/humbly-plural`

### Option 4: Netlify
1. Go to https://netlify.com
2. Sign up
3. Drag and drop the `index.html` file into Netlify
4. Your app is live at a random URL
5. You can customize the URL in settings

## Features

- ✅ Add/edit/delete members with names, pronouns, roles, descriptions
- ✅ Track fronting with start/end times and notes
- ✅ Write and manage journal entries
- ✅ View system statistics
- ✅ All data stored locally in browser (no server needed)
- ✅ Works on phone or computer
- ✅ No installation required

## How it works

- Open the link in any browser
- All data is saved to your browser's local storage
- Data stays on your device, nowhere else
- Works offline too (after first load)

## Share the app

Once hosted, just share the public URL with anyone who wants to use it.

Example: "Check out my plural system app at https://humbly-plural.glitch.me"

## Privacy

- All data is saved locally in your browser
- Nothing is sent to a server
- No tracking or analytics
- Complete privacy and control
